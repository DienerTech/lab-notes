# Projects

One folder per production. Each one holds a case study, sample prompts, small media, and anything specific to that project.

| Project | Year | Models and tools | Status |
|---|---|---|---|
| [Can You See Me Now](can-you-see-me-now/) (EVE Online AMV) | 2026 | MiniMax H3, GPT Images, Remotion, code previs | Released |

To add a project, create `projects/<slug>/README.md` following [CONVENTIONS.md](../CONVENTIONS.md). Lessons that hold beyond one project go into `models/`, `techniques/` or `workflows/`, with a link back here.
